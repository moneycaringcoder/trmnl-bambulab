Bambu Lab printer display — help

This plugin puts your Bambu Lab printers on a TRMNL e-paper display. An idle printer shows its name and Ready; a printing one shows progress, and — when the richer data source is available — layer count, time remaining and temperatures.

Read-only, always. This plugin never sends a command to a printer. It cannot pause, stop, heat, move, or start anything — the code that talks to Bambu has no ability to write, by construction.

Setting it up

  1. Install the plugin in TRMNL. You'll land on the setup page.
  2. Connect Bambu Cloud: pick your region, enter your Bambu account email, and type in the code Bambu emails you. There is no password step — the emailed code is the whole sign-in, so we never see or store your Bambu password.
  3. Choose up to three printers. The first one leads the display.
  4. That's it. The display updates on your TRMNL refresh schedule.

Changing things later

Open the plugin's settings in TRMNL and follow its configure link back to the setup page. From there you can change which printers show, sign in to Bambu again if your session expired, or delete everything.

What the screen shows, honestly

  • A metric that isn't available is left out rather than shown as zero. A blank is honest; a fabricated 0% is not.
  • If a reading is old, the display says so instead of presenting stale numbers as current.
  • Job names are not shown unless you opt in, since they can reveal model names.

What we store

We store the printers you chose, your region, an encrypted Bambu Cloud session token, and the last rendered screen. We never ask for a password, and we discard your email address after sign-in. Uninstalling the plugin in TRMNL deletes all of it immediately.

Prefer to run it yourself?

There is a self-hosted version with richer live telemetry that runs on your own machine and never sends data to us. It lives in the same open-source repository as this plugin.

Something broken?

If the display says Not set up, open the plugin's configure link and finish connecting Bambu. If it says Waiting, the first reading is on its way — give it five minutes. Anything else: open an issue on the project repository, and never paste a code, token, or serial number into a report.
